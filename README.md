# Home Card Printer (web)

Open **https://holmeski.github.io/card-printer/** in Safari on an iPad (Share → Add to Home Screen) or any browser.

Paste a decklist (Moxfield → Export → Copy for MTGA) and it makes print-ready PDFs for blank 2.5" × 3.5" poker cards on a Canon PIXMA G620: one card per 3.5" × 3.5" borderless page, double-faced cards first, optional card backs, in parts of 20.

The whole app is `index.html`. For personal playtest use.
